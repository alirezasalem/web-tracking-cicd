# remove_from_cart

Tracks when a user completely removes an item from their shopping cart.

## Overview

This event fires when a customer clicks the remove button to delete an item from their cart on the cart page. It captures the removed item's details along with cart value snapshots before and after removal. This data helps the merchandising team understand cart abandonment patterns and identify products that are frequently removed after being added.

## Trigger Rules

- User clicks the remove item button (`[data-testid="remove-item-btn"]`) on the `/cart` page
- The item must be **completely removed** from the cart, not just reduced in quantity
- User must have at least one item in their cart before removal
- Must NOT fire on quantity decrease actions (e.g., changing quantity from 3 to 2)
- Must NOT fire duplicate events on rapid successive clicks of the same remove button
- Must fire only once per removal action, even if the user clicks repeatedly before the UI updates

## Business Rules & Edge Cases

1. **Complete removal only**: This event tracks full item removal. If a user decreases quantity (e.g., from 3 to 2), do NOT fire this event. A separate quantity change event should handle that scenario.

2. **Debounce rapid clicks**: Implement a debounce mechanism (recommended: 500ms) to prevent duplicate events when users click the remove button multiple times quickly before the cart UI updates.

3. **Currency formatting**: All monetary values (`value`, `cart_value_before`, `cart_value_after`, `price`) must be numeric with up to 2 decimal places. Do not include currency symbols or thousand separators.

4. **Cart value calculations**: `cart_value_before` should equal `cart_value_after` + `value` (within rounding tolerance). If cart state is unavailable, omit the optional cart value parameters rather than sending incorrect data.

5. **Items array**: Always send exactly the item(s) being removed in this action. If multiple items are removed in a single action, include all of them in the items array.

6. **Quantity reflects removal**: The `quantity` field in items[] should reflect how many units were removed, not the quantity that was in the cart before removal.
